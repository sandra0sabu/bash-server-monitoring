⚡ Bash Server Monitoring

🖥️ Monitor Smart. Alert Early. Stay Reliable.

A lightweight Linux monitoring tool built with Bash scripting to monitor disk and memory usage and send email alerts when resource usage exceeds a configured threshold. 🚀

✨ Features

💽 Disk Usage Monitoring

🧠 Memory Usage Monitoring

📧 Automated Email Alerts

⚙️ Configurable Thresholds

🐧 Linux and Ubuntu Support

🪶 Lightweight and Beginner-Friendly

🛠️ Tech Stack

🐚 Bash Scripting

🐧 Ubuntu Linux

📬 Linux Mail Utility

🔗 Git and GitHub

🚀 Getting Started

1. Clone the Repository

git clone https://github.com/sandra0sabu/bash-server-monitoring.git
cd bash-server-monitoring

2. Make the Script Executable

chmod +x server_monitoring.sh

3. Run the Script

./server_monitoring.sh

⚙️ Configuration

Configure the threshold and email address in server_monitoring.sh.

THRESHOLD=4
EMAIL="your-email@example.com"

💡 Tip: A low threshold is useful for testing email alerts. For regular monitoring, choose a threshold appropriate for your system.

📬 Email Notifications

Receive email alerts when monitored resource usage exceeds the configured threshold.

📌 Email delivery requires a working mail utility and a properly configured email-sending service.
